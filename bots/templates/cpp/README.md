# C++ bot template

A starter bot: it puts each stone on a random legal point and splits its weight evenly over
its stones. Write your strategy in the section of `bot.cpp` marked `EDIT ONLY THIS SECTION`.

Copy this whole folder to `bots/<your-name>/`. The referee finds it there by itself; press
**Rescan** on the dashboard. Working examples are in `bots/samples/`. See the main README,
"Making a bot".
