Gravitational Voronoi

architecture & tournament referee · every bot runs on this machine

1 Bots

Read from bots.json, plus any folder dropped into bots/ that holds a bot.py, bot.cpp or bot.jl. To add a classmate's bot, unzip their folder into bots/ and press Rescan.

2 Parameters

Each file holds the stones each player places and the total weight each player may spread over them. The board is 1000 × 1000 and stones must be at least 66 apart.

3 Matches

A match between two bots is two games with the same parameters: each bot moves first once. Each bot keeps its colour for the whole match: the first bot in the row is red, the second blue, and so on. A bot's score is its territory over both games added together. A melee is the same with more bots: one game per bot, the seats rotating so every bot sits in every seat once. To play just one game instead, choose 1 game on the row: the first bot in the row moves first. An illegal stone skips that turn and is logged.

Choose bots and matches, then start.
